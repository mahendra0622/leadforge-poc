### 1. Fixed financial metrics not showing in UI
- **Root cause**: SQLAlchemy's JSON column silently drops in-place dict mutations (`rd.update(...)` when `rd` is the same object as `co.regulatory_data`)
- **Fix**: Assign a new dict `co.regulatory_data = {**rd, **metrics}` AND call `flag_modified(co, "regulatory_data")`
- File changed: `backend/compute_financial_metrics.py`
- Deployed via Render one-off job — succeeded in ~30s
